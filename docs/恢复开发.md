## 新电脑恢复代码

```sh
git clone https://github.com/sunruize93-cmyk/anc-card.git
cd anc-card
npm ci
```

Node.js 要求 22.13+。先运行 `npm run verify` 检查离线流程。安装完整 Xcode 后按 [iPhone 构建说明](../relay/ios/README.md) 编译；真机不依赖 iOS 模拟器，清理模拟器不会删除手机上的 App。若以后要跑模拟器，可在 Xcode 的组件设置中重新下载。

SpeakMode 重新安装见 [项目首页](../README.md)：`sh prototype/scripts/setup-speakmode.sh`。这会重新构建已固定版本的工具，需 Rust 和 Apple 开发工具。旧 Mac 已安装的转写程序与配置本次保留，不需要重复安装。

## GitHub 能恢复什么，不能恢复什么

公开仓库包含源码、固定依赖清单、测试、开发计划、脱敏实测报告和分享 PDF。Xcode/Swift/Rust 构建缓存、真机调试符号和安装包均可重新生成或下载，无需提交。

公开仓库不包含真实录音、SQLite 任务历史、飞书应用密钥、设备上传凭证、证书私钥、Apple 签名身份和 Codex 登录/会话记录。新电脑可以从仓库重新开始开发，但要继续原任务和原卡片，必须安全迁移原私有状态；否则应重新配置并创建新测试任务，不能宣称历史已恢复。

当前 Mac 的私有状态与正在运行的服务保留。不要删除 `.anc-data`、本机钥匙串、`~/.local/share/anc-card` 中的配置和已安装工具，也不要把这些内容提交到公开仓库。实际服务可能使用 `.anc-data` 下冻结的代码快照和指定数据目录；切换服务前先核对当前进程与启动参数，不能直接另开一个服务造成重复消费。上传 HTTPS 配置见 [原生上传说明](../relay/ios-upload/README.md)。
