## 本轮唯一目标

一人、一张A卡、一部iPhone、同Wi-Fi、Mac在线、飞书一个主bot：

> 锁屏录一条60–90秒的明确任务 → 保存 → 无需重开App自动取回完整原音并上传 → SpeakMode/百炼转写及带原音时间引用的结果 → 负责人确认 → Codex首轮与同会话续跑 → 原任务卡回写 → 负责人验收。

最终验收必须来自**同一条新真实录音**。不同录音、Mac合成音频、旧执行器样例不能拼接成一次完整通过。
