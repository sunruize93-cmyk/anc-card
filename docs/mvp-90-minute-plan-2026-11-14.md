## MVP只定义一个终点

Eric.s、一张A卡、一部iPhone、同Wi-Fi、当前Mac在线、nestlinker work一个主bot：

**锁屏录一条60–90秒的明确任务 → 保存 → iPhone无需重开App自动下载上传 → 原音完整可核对 → 真实转写和带时间引用的结果卡 → Eric.s确认明确执行范围 → Codex首轮 → 同会话续跑 → 同一任务卡回写 → Eric.s验收。**

这是本机短录音MVP。不是两小时会议、五人、公网、24小时产品的验收。若锁屏完整性门槛失败，只能交付前台可用演示和明确阻塞，不改口宣称锁屏MVP完成。语义范围使用明确的“由Eric.s负责”话术；不宣称通用Coffee Chat理解已解决。
