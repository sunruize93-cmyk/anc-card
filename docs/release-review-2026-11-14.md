## 审查发现与优先处理项

1. **长音频容量门槛**：当前音频输入上限 64 MiB；16 kHz、单声道、16 bit 的两小时 PCM 约 230 MB，不能直接沿用短 WAV 上传路径。需压缩格式或可靠分块方案，并保留全文件身份与连续时间范围。
2. **任务理解有限**：普通提取仍依赖明确表述；Coffee Chat 回放有固定场景。结构化文档生成也需要人工核对，不能当作通用自主派发已完成。
3. **失败后的恰当恢复**：录音超时重试和执行恢复分别处理；不能因丢回执就再执行一次。远程实验保守地只启动一次，崩溃后需人工核对，不保证自动完成。
4. **证据缺口**：原始批准回调、完整卡片更新回执、独立授权标识、完整事件窗口需补齐。当前完成判断有业务证据，但不声称零缺口审计。
5. **文字与版本一致性**：入口 README 已更新，旧进度页标历史。原卡旧执行摘要可能仍说“待验收”，须下一轮统一文案，不在本轮重启服务或改已有证据凑一致。
6. **多设备与公网仍待办**：当前可演示的一人同网流程与五人日常使用之间仍有权限、凭证、联网、安装升级和长期维护工作。
