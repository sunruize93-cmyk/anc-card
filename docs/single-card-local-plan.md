## 下一步，仅一张卡

1. **接收现成 iOS 源码。** Zoty 在群里交 relay-ios 的源码包、已有测试和 BUILD-ON-MAC.md。当前群消息尚未看到该包；不催他补新开发或硬件实验。
2. **Eric.s 端集成。** 核对包哈希、协议测试和入口，将旧上传约定改为已验证的 `/v1/recordings`、稳定 localId、SHA-256、TLS 与回执检查。编译安装到当前 iPhone。
3. **只读前台 BLE。** A 卡拔 USB、开机；释放其他电脑／官方 App 对卡的连接。iPhone 授权蓝牙、识别并绑定指定卡、列文件、取回一份旧录音。完整性检查后才入上传队列，不删除机身原件。
4. **第一条自动闭环。** App 保持前台，在卡上录一条新测试口令并按保存。只操作卡，不点手机导入或上传；应自动发现新文件、下载、校验、持久化、上传、转写并出现新的飞书结果卡。
5. **不重复。** 卡重新连接、App 重新打开后，对同一份录音不创建新任务或新结果卡。查看时间点能回到原音；记录卡保存、手机落盘、后台入队、飞书投递四个时间。
6. **恢复与锁屏。** 前台流程通过后，再分别测下载中断、网络中断、正常锁屏。每项用一条新短录音；系统强退和重启另列，不把前台成功计作后台无限运行。

首条建议口令：

> 这是 A 卡自动同步验收。由 Eric.s 负责接口示例和调用说明，接口遇到四二九时只重试一次，截止时间是本周五。

保留“本周五”的原话，不凭文件名或设备时钟擅自解析日期。飞书结果卡出现是本轮终点；如果后续执行 Codex，仍需负责人确认。

## 本机运行条件

- Mac 后台 `127.0.0.1:4785` 与手机上传入口 `192.168.0.11:4787` 在本轮检查时都监听；地址是现场状态，换网后重新检查。
- Mac 接电、保持唤醒且后台在运行，手机连接同一 Wi-Fi；合盖、休眠、换 Wi-Fi 均可能使入口不可达。
- 设备凭证为短期配置，到期在本机更新，不把它或 API Key 发群里。录音先保留手机副本，收到可核对回执才标记上传成功。
- 当前短文件限制 64 MiB；先验收 20–30 秒。长会议分段和跨网络上传暂不作为这一步的通过条件。
