# 一小时录音、2 路转写与故障恢复实测

日期：2026-11-15（韩国时间）。**只在隔离目录测试；手机、当前主后台与上传网关没有改动或重启，默认并行度仍为 1。**

## 结果

一条自制中文录音，时长 **60 分 32.923 秒**，116,253,580 字节；53 节有已知原文的虚构讨论，含负责人、金额、编号及日期改口。macOS Tingting 语音，每节额外留一秒静音，没有以大量静音凑一小时。语句结构重复，不能代替真实多人、噪声、口音或多语会议的质量测试。

使用现有 SpeakMode、`qwen3-asr-flash`、自动语种和原有分段规则，共 **159 个切片**，最大并发始终为 **2**。没有修改分段长度、生产配置或手机。

总耗时包含导入、归一化、ASR、本地结果入库、恢复和证据记录；不含语音合成、卡到手机、手机上传、飞书投递及总结。三个阶段合计是处理同一录音的全过程，不是三次完整转写。阶段耗时之和与总耗时的差额来自阶段间核对和记录。

这是一次一小时样本的 2 路运行，不是重复多日稳定性统计，也没有本条录音的串行/4 路对照；不能从中宣布相对串行加速多少，或承诺真实两小时会议的完成时间。

## 两次恢复怎样验证

1. **片段失败**：在索引 31（原音 11:46.440–12:16.440）调用云端之前，测试适配器主动报错。已有 31 个片段成功落盘；队列停止派发并等待在途调用结束。新进程打开同一隔离数据库，显式重试同一录音，跳过这些成功结果。
2. **进程崩溃**：已有 87 个片段落盘、还有两个请求在途时，对独立测试进程组执行 SIGKILL，包括它自己的 SpeakMode 子进程。主服务和网关不在该进程组内。数据库保留 processing 状态，完整性检查通过。
3. **自动恢复**：第三个进程打开同一数据库后，自动重排这条未完成录音，复用 87 个已保存结果，最终得到全部 159 段。所有已保存片段的文字及证据字段完全不变，后续阶段没有再次请求它们。
4. **重复导入**：完成后以另一个文件名再次导入相同音频，返回 duplicate；数据库仍是一条录音，53 个待审核行动项，没有重复生成任务。

被杀掉的索引 87、88 没有落盘，因此重启后重新请求。这解释了 161 次启动与 159 个结果之间的差额。云端可能已接收被中断的两次调用，不能保证它们免费、被取消或只执行一次。

**人工注入错误与真实供应商故障分开记录。** 本次真实请求没有触发超时、断网或限流；不能把这次成功恢复说成这些网络情况全部通过。原有单段超时最多重试一次仍由离线回归覆盖。

## 原音时间点与文字质量

- 原有分段起止位置、顺序和 PCM 哈希全部保留。输出覆盖 0–3,632,600 毫秒；尾部 323 毫秒经原 PCM 核对为全静音，未丢弃有声区间。
- 时间点是原音的**片段范围**，不是逐词对齐。首、中、尾的编号与文字均保留；所有行动项引用的范围、哈希及证据文字都能对应到同一转写片段。
- CER 忽略标点、空白、大小写；保留文字差异。53 节的五项检查共 265 次，句式重复，不能视为 265 个独立任务或语义准确率。
- 仍有误字和漏字。例如第一节“其余部分先保留”在切片边界附近变成“其余部分先保”；第二十七节“最后提醒大家”合并后变成“最后提请大家”。“当作”也有“当做”的写法差异。下一步应单独比较断句与少量重叠切片，不能把并行恢复通过当作无误转写。

## 一个另外暴露出来的任务问题

53 节都先说“下周五”，随后改为“下周一”；修改和取消的文字在转写中均命中。**现有规则式行动项仍将 53 项截止时间写为“下周五”**，因为它只取局部片段中的首个期限，没有跨段合并改口。

这些任务仅写入隔离测试台账，状态为待审核，未发飞书、未交给 Agent 执行。本轮不改任务派发代码。长会议正式派发前，应先补齐跨段改口、撤回和最终决定核对；全文转写完整不等于行动项正确。

## 测试与资源边界

- 新增真实子进程 SIGKILL 的离线工具测试：1 项通过，包含恢复、缓存不重复调用、证据覆盖拒绝及源文件哈希变化拒绝。
- `npm run verify:asr-parallel`：16 项通过；`npm run verify`：原有队列流程及 34 项通过。
- 另用同一小时样本做了不调用云端的恢复预演；预演的文字与速度不计入上述真实结果。
- 采样观察到单个队列工作进程最高 RSS 约 729 MiB；不含父进程、SpeakMode 子进程和已有服务，也不是精确整体峰值。当前整文件读入及 SQLite BLOB 方式仍有内存成本，不能直接按“五个人使用”推断小服务器容量。
- 开始与结束检查主后台 PID 95013、网关 PID 96196 保持不变。本轮没有操作 iPhone、录音卡、生产数据库或真实飞书卡片。
